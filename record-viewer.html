Battle records

Read an agent battle round by round: each commander's orders, notes and radio lines, on a map of where things were sent, beside the raw JSON. A battle record is the .json file an agent battle writes to battles/.

Open one from your computer, drop it on the page or paste it. Or load one by its link: any URL whose server allows other sites to read it (CORS), a file on GitHub, or a Gist. The link goes in the address bar as ?replay=, so you can bookmark it or pass it on.
